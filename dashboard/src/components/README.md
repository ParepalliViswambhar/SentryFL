# Components Directory

This directory contains reusable React components for the SentryFL Dashboard.

## Purpose

- Reusable UI components (buttons, cards, tables, charts)
- Layout components (header, sidebar, footer)
- Form components
- Visualization components (metric displays, charts, graphs)

## Component Structure

Each component should follow this structure:
```
ComponentName/
  ├── ComponentName.jsx
  ├── ComponentName.module.css (optional)
  └── index.js (export)
```

## Examples

- `MetricsCard` - Display training metrics
- `PrivacyBudgetChart` - Visualize privacy budget consumption
- `ExperimentTable` - List experiments
- `AnomalyTimeSeries` - Display time-series with anomaly predictions
