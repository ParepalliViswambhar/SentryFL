# Pages Directory

This directory contains page-level components for the SentryFL Dashboard.

## Purpose

- Top-level route components
- Page layouts and compositions
- Integration of multiple components

## Expected Pages

- `Dashboard` - Main dashboard overview
- `Experiments` - Experiment management and control
- `ExperimentDetails` - Individual experiment view with metrics
- `Results` - Analysis and comparison of results
- `Configuration` - Experiment configuration management
- `Privacy` - Privacy metrics and MIA evaluation results
- `Communication` - Communication scaling analysis

## Page Structure

Each page should:
1. Define its own layout
2. Compose multiple components
3. Handle data fetching
4. Manage page-specific state
